Phase 0 — Share Visibility Spike

Answering one question: does a transparent, always-on-top, layered overlay show up in a monitor share on Teams and Zoom? Everything in Zemo depends on yes.
This window is capture-excluded, so a viewer should never see it.

Test protocol

  1. Start a call with a second participant (a phone or second machine works).
  2. Share Screen / Entire Screen — not a window.
  3. Ask: "can you see a red frame and a counting clock?" → that's Test A.
  4. Hit Exclude overlay below. They should see it vanish, then return when you turn it off. This is the positive control — it proves the share is really capturing our window, so a "no" in Test A is a genuine negative.
  5. Change the accent colour and have them confirm it live. Rules out a stale frame.
  6. Ask whether they can see this control panel → that's Test B. They should not.
  7. Repeat all of it on the other platform (Teams, then Zoom).
  8. Record results in docs/plans/01-share-visibility-spike.md.

Overlay

Exclude overlay is the positive control for Test A. Make interactive drops click-through — the overlay will swallow your clicks, and it also checks that transparency survives the toggle (the bug that set_click_through_preserving_layered exists to prevent).

Accent colour — liveness check

This control panel (PRD R4.2)

Turn this off and the viewer should suddenly see this panel appear in the share. That confirms exclusion is doing real work rather than silently no-op'ing.
