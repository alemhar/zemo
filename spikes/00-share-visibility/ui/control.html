Tool

Marks 0

Newest is undo — it walks back the way you drew. Oldest drains from the front, so a sequence of marks retires in the order you made it. Both work while you're in pass-through, so you can retire marks without re-arming.

Picking a tool arms draw mode. Arrow is tail-first — press where the arrow starts, drag toward the thing you're pointing at. Right-click cancels mid-draw. Turn test graphics off for a clean surface.

Overlay

Exclude overlay is the positive control for Test A. Make interactive drops click-through — the overlay will swallow your clicks, and it also checks that transparency survives the toggle (the bug that set_click_through_preserving_layered exists to prevent).

Overlay geometry — run this before the call

Frameless Windows windows have an invisible resize border (often ~8px on left/right/bottom, 0 on top). Windows positions the outer rect including that border, but WebView2 draws inside the inner one — so without compensation the overlay sits shifted off the monitor edge. The amount varies by Windows version, DPI and theme, so it is measured on each machine rather than assumed.
